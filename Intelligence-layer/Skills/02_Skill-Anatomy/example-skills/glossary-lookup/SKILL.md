# Glossary Lookup

## When to Use
When the user asks what an internal acronym, code name, or domain term means (e.g., "what is an MQR?"), or asks you to expand a term used in a document.

## Workflow
1. Identify the term or acronym the user is asking about.
2. Look it up in the team glossary the user provides or points to.
3. Return the expansion plus a one-sentence, plain-language definition.
4. If the term is not in the glossary, say so plainly — do not guess a meaning.
